# 💳 Nitin Enterprise — UPI Payment Landing Page

A modern, mobile-first UPI payment website for **Nitin Enterprise**, an Internet & Cable TV provider based in Rudrapur, Uttarakhand.

Built using **HTML, CSS, and Vanilla JavaScript** with no backend or payment gateway.

---

## 🌐 Live Demo

https://nitinenterprise.in

---

## ✨ Features

- 💳 Dynamic UPI QR Code Generator
- 📱 Pay via UPI Apps (GPay, PhonePe, Paytm, BHIM)
- ⚡ Quick Pay
- 📋 Copy UPI ID
- 📥 Download QR Code
- 📤 Share QR
- 👤 Customer Name
- 💰 Amount Validation
- 🧾 Payment Summary
- 📞 Call Support
- 💬 WhatsApp Support
- 📍 Google Maps
- 📱 Progressive Web App (PWA)
- 🎨 Clean & Responsive UI
- ❓ FAQ Section

---

## 🛠 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- QRCode.js
- Lucide Icons
- Google Fonts
- Service Worker (PWA)

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/your-username/nitin-enterprise.git
cd nitin-enterprise
```

Open `index.html` in your browser.

No installation required.

---

## 🚀 Deployment

Deploy easily on:

- GitHub Pages
- Vercel
- Netlify
- Any Static Hosting

> HTTPS is required for full PWA functionality.

---

## ⚙ Configuration

Update your details in `pay.js`:

```js
const UPI_PA = "tradesnitin1-1@okicici";
const UPI_PN = "Nitin Trades";
const WA_NUMBER = "918630473928";
```

Replace:

- QR Code
- Phone Number
- Address
- Google Maps Link
- Business Details
